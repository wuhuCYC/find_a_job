# 签证与工作许可（F-1 STEM 硕士视角，截至 2026-09-24）

> ⚠️ **这不是法律意见。** 2025–2026 年移民政策变化很快，多项规则还在诉讼或立法过程中。
> 行动前请向 **UCI International Center（你的 DSO）** 或持牌移民律师确认。
> 前提假设（请确认）：你持 F-1、EECS 硕士（STEM 专业）、2026 年前后毕业。
> 完整调研（75 个带日期的出处）：[research/visa_2026.md](./research/visa_2026.md)

## 1. 现状一览

| 事项 | 状态 | 对你意味着什么 |
|---|---|---|
| 12 个月 OPT + 24 个月 STEM OPT | **有效** | 照常可用 |
| 失业天数上限 90 天（加 STEM 后共 150 天） | **有效** | 从 EAD 生效日开始算，不是从毕业开始 |
| STEM OPT 要求雇主加入 **E-Verify** + 签 **I-983** 培训计划 | **有效** | 投递时优先 E-Verify 雇主（打分器会识别 JD 里的 E-Verify） |
| DHS 取消 "duration of status" 的新规（2026-07-17 发布） | **被法院叫停**（2026-09-14 全国禁令） | 旧规则继续适用；政府可能上诉 |
| OPT 收费提案 | **已过白宫审查（2026-09-11），尚未公布** | 金额未知（媒体报道曾考虑 $100K）—— 重点关注 |
| SEVP 收紧 CPT（2026-08） | **有效** | Day-1 CPT 现在风险很高，不建议 |
| $100,000 H-1B 总统公告 | 公告延期到 2027-09-21，但**执行被法院撤销**，目前不收 | **从来不适用于在美国境内 F-1 转 H-1B** |
| 每个 cap H-1B 申请加收 **$103,265** 的提案 | **提案阶段**（2026-08-25 发布，评论期 9-24 截止） | **最大的变数**：如果落地，F-1 转 H-1B 也要交；大学等 cap-exempt 雇主不适用 |
| H-1B 抽签按工资级别加权 | **有效**（FY2027 已使用） | Level II 工资大约是 Level I 两倍的中签权重 |
| 劳工部提高 prevailing wage 的提案 | **提案阶段** | 如果落地，新人工资门槛再提高 |
| FY2027 抽签 | 已结束，2026-07-17 名额用完，无第二轮 | 注册量报道下降约 38% |

## 2. 对求职的实际影响

**筛选雇主时优先看**：

1. **E-Verify 注册**的直接雇主（W-2），不是外包/派遣公司
2. **2025–2026 年仍有新人 H-1B 申请记录**（h1bdata.info / myvisajobs 可查）
3. 给的工资能达到你岗位代码 + 地区的 **Level II 或以上**（在 DOL 的 FLAG wage search 查；Irvine 属于 Anaheim-Santa Ana-Irvine 地区）
4. **cap-exempt 雇主**（大学、附属非营利研究机构，包括 UC 系统的研究岗）作为保底
5. 如果你是中国国籍，避开需要 export control / security clearance 的岗位（打分器会标记）

**好消息**：按工资加权的抽签对**高薪的量化 / 资管岗位**是利好 —— 这和你想走的方向是一致的。

**面试里怎么问担保**（第一轮 recruiter call 就可以问，很正常）：

- "Does the team support STEM OPT (E-Verify, I-983)?"
- "Would the company register me in the H-1B lottery next March?"
- 关于 $103K 提案：可以问公司对新规的态度，但别在第一句话就问。

## 3. 时间线与坑

> 在 `private/profile.yaml` 填 `program_end_date`（以及 `opt_filed_date`、`ead_start_date`），
> 网站「签证」页会按下面的规则算出你自己的截止日期。

**算法**（以学校国际学生办公室为准）：

| 节点 | 怎么算 |
|---|---|
| OPT 最早提交 | 项目结束日前 90 天 |
| **OPT 提交截止** | 项目结束日后 60 天（也是 60 天宽限期的最后一天；还要在 DSO 推荐后 30 天内提交） |
| EAD 开始日 | 只能选在项目结束后的 60 天内 |
| 失业上限 | 从 EAD 开始日起累计 90 天（STEM OPT 再加 60 天，共 150 天） |
| STEM OPT 申请 | OPT 到期前 90 天起可以申请，需要 E-Verify 雇主 |
| H-1B 注册 | 每年 3 月，需要雇主在此之前愿意为你注册 |


- **OPT 申请窗口**：项目结束日前 90 天到结束后 60 天；DSO 录入推荐后 30 天内必须提交。**如果 2026 年 12 月毕业，现在已经可以申请了，尽早。**
- **90 天失业计时**从 EAD 上写的开始日期算。开始日可以选在毕业后 60 天内 —— 如果还没 offer，可以适当往后选，给自己留缓冲。
- **找到工作后 10 天内**在 SEVP Portal 报告雇主，否则算失业。
- H-1B 转换身份（change of status）审批期间**不要出境**（出境会放弃申请，并可能触发高额费用问题）。
- 你大约有 **三次抽签机会**（2027 年 3 月、2028 年 3 月、2029 年 3 月，前提是拿到 STEM OPT）。
